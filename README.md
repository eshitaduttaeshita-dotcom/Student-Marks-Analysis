# Student Marks Data Analysis

## About Project
This project analyzes student marks using Python
and Pandas.

## Features
- Read student data from CSV file
- Calculate average marks
- Find highest and lowest marks
- Identify student topper
- Calculate Pass/Fail results
- Display bar charts

## Technologies Used
- Python
- Pandas
- Matplotlib

## Dataset
The dataset contains student names and marks.

## How to Run

1. Install Python.
2. Install required libraries.
3. Run the following command:

python student_analysis.py
